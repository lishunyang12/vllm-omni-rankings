# MiniMax-H3 two-prompt quality generalization A/B

This page contains the four generated full-video artifacts for a quality check
of the cumulative stack that keeps QKV transport in BF16. Artifact generation,
structural validation, and metric computation are complete; the complete-video
human quality decision remains pending:

- Control: BF16 main-DiT linear execution + BF16 QKV wire + full H3 VAE.
- Candidate: all-main FP8 linear execution + BF16 QKV wire + TAEH3 FP16.

Both sides retain the same FastH3 VSA/Data-Free student, four transformer
evaluations, tile size 64, top-k 162, TP1/SP8 placement, NCCL Ulysses transport,
seed 1101, prompt, canvas, and MP4 contract. E4M3 QKV transport is excluded
because it failed the earlier complete-video quality gate. Skip-softmax is also
excluded, so neither rejected/approximate attention change is hidden inside the
candidate.

## Interpretation boundary

This is a shape/style generalization and complete-video human-review page. It
is not a performance qualification. Each MP4 is generated by a single
no-warmup request, but server order, first-request compilation, persistent disk
and JIT caches, and unlocked clocks can differ between artifacts. The eventual
artifact-local E2E/RTF values are provenance only: do not subtract them, divide
them, or use them to claim a factor speedup or real-time result.

NCCL is deliberately held constant across all four cells. The production RDMA
and reverse-O bundle route is currently qualified for a different 1280×704,
362-frame geometry, so it is not generalized silently to these new shapes.
