Abstract

We evaluate an offline rank-32 SVDQuant checkpoint and a native fused W4A4 execution path for MiniMax-H3 video-audio generation. The implementation quantizes the residual linear branch to NVFP4 while retaining a low-rank BF16 correction, then fuses residual GEMM, rank-up, scalar or per-output scaling, and bias in a FlashInfer/CUTLASS kernel. On one NVIDIA B300 SXM6 AC, under a matched T2VA workload with one complete 50-step warmup and three complete measured rounds, mean end-to-end latency decreases from 134.599 s in BF16 to 103.977 s, a 1.2945x speedup. Mean denoise latency improves by 1.3129x and measured worker peak memory falls by 34.25%. A no-cache control reaches 1.2305x, isolating an additional 5.408 s of E2E savings from four B300-specific kernel tactics. All 208 targeted transformer linears use the native path, including 52 QKV projections with per-output alpha.

Keywords: SVDQuant; NVFP4; W4A4; diffusion transformer; video generation; kernel fusion; Blackwell; MiniMax-H3

3. Quantized Architecture

SVDQuant decomposes each selected linear into a quantized residual branch and a rank-32 correction branch. MiniMax-H3 QKV uses three logical shard scales; per-output alpha support folds these scales into the native epilogue and raises native coverage from 156/208 to 208/208 linears.

The implementation folds 1 / alpha row-wise into L1. Consequently, the epilogue may scale the shared accumulator by either a scalar alpha or an N-element per-output vector without incorrectly scaling the low-rank correction.

6. Correctness, Precision, and Scope

  • Dispatch coverage: 208/208 targeted linears select native fused SVDQuant: 156 scalar-alpha linears and 52 QKV linears with vector alpha.
  • Kernel numerics: scalar and per-column alpha, bias/no-bias, autotuned execution, and linear reference checks pass the FlashInfer GPU tests.
  • Integration numerics: the vLLM-Omni backend tests cover the fallback reference, native scalar contract, and native per-output-alpha contract.
  • Run stability: measured frame and audio hashes are stable within each recipe; tuned E2E CV is 0.135%.
Scope limitation. These performance numbers validate NVIDIA B300 (SM103), this exact MiniMax-H3 workload, and this software stack. SM100 is supported by the kernel family but needs its own tactics; RTX Blackwell SM110/SM120/SM121 remains on a compatible fallback until a native port is validated. Three measured rounds are sufficient to establish repeatability for this engineering run, but not to estimate fleet-level tail latency. Perceptual fidelity is not inferred from latency hashes; consult the paired visual matrix.
