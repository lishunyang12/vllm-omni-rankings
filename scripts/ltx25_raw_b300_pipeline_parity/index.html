Each task receives one excluded full 50-step warm-up followed by two timed requests. Timing starts before the loopback POST /v1/videos/sync and stops only after the complete MP4 body is received; startup, model load, warm-up, file writing, and validation are excluded. These clips align the difficult prompt, seed, GPU count, FPS, and approximately five-second playback with the LTX gallery. This is intentionally not an equal-compute or same-backend speedup claim: LTX above uses 1920×1088, 121 frames, and cuDNN; MiniMax-H3 uses 1344×768, 124 frames, and TRTLLM_ATTN.

Official uses pinned raw LTX-2.5 split artifacts and the pinned Lightricks runtime. vLLM-Omni uses the equivalent materialized checkpoint at head f7e2d68364fd. Both sides use BF16 cuDNN attention, the same connector weights, prompt, conditioning, schedules, and RNG seed.
