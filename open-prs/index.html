排名与数据口径 How this works＋

完整范围：遍历 GitHub 上 vllm-project/vllm-omni 的所有 open PR，包括 Draft 和 Bot 作者；不受搜索接口 1,000 条结果上限影响。贡献者仅包含当前至少有一个 open PR 的账号，已合并和已关闭 PR 不计入。

排名：默认按 open PR 数量降序，同数量并列；状态筛选和 Bot 开关会重新计算排名，用户名搜索只过滤列表。也可按最近更新时间排序。这是进行中工作量的视图，不是个人能力或质量评分。

状态：只统计 open PR，区分 Draft 与非 Draft。点击标题或编号即可打开 GitHub 原始 PR。数据不包含 CI 和 Review。

更新：每小时自动抓取一次，更新和部署可能延迟。「刷新数据」读取最新已发布快照。数据抓取期间若总数变化会重试；失败保留上次完整快照，不发布残缺排名。界面显示你的本地时间。
