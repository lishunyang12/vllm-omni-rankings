Classification & methodology How this works＋

Rules, not a code review. Topics come from keyword rules applied to PR titles and GitHub labels. No PR bodies or diffs are analyzed. Open “Why these topics?” on a PR to inspect the evidence. Unmatched PRs remain under Unclassified.

Multiple topics. One PR can mention a model, hardware, and several technical areas. Match all finds intersections; Match any finds the union. PR totals and CSV exports always count each PR once.

Hardware mentions. A hardware topic means the title or label mentions that platform. It does not establish compatibility or test success. Tests / build identifies the subject of a PR; CI results and reviews are not collected.

Committers. Exclusion uses Active Committers and Lead Maintainers in the public governance roster, refreshed with each snapshot.

Coverage. This view shares the complete open PR snapshot with the contributor leaderboard. Closed and merged PRs are excluded here. Unknown future model names may need new rules.

Updates. Collected hourly; publication may be delayed. Refresh data reads the latest published snapshot. Your topic selection is saved in the URL for sharing. Inspect classification rules ↗
